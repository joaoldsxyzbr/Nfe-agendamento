# NFe Agendamento 2.0 — v0.0.38

Release de robustez Portal-only com extensão **0.2.14**, decorrente da auditoria técnica de 13/10/2026 (#77).

## Alterações

- A captura oficial do XML passa a ter timeout de **45 segundos** e leitura incremental com limite de **10 MiB**, evitando acumular uma resposta ilimitada antes da validação.
- Um timeout ou XML excessivo encerra a operação com erro explícito, preservando as opções de reconsulta ou importação manual.
- Eventos do Portal recebidos durante tarefas assíncronas não são descartados: são reconciliados quando a tarefa terminar, sem introduzir polling.
- Cancelar enquanto o Portal ainda abre encerra a operação assim que o ID é recebido, evitando deixar um popup órfão.
- Falhas ao verificar a extensão antes do lote geram mensagem de recuperação, sem travar os controles.
- Novos testes para streaming, limite, timeout, comportamento real do content script (DOM simulado), sinalização assíncrona e cancelamento tardio.
- Elevação conservadora dos limiares de cobertura web/extensão e novos thresholds específicos para o content script e streaming.
- `AGENTS.md` atualizado para o plugin **Assistente**, preservando o roteamento por especialistas.

## Escopo preservado

- Portal Nacional continua como única rota de consulta; hCaptcha é **manual**.
- Sem novas permissões, endpoints, certificados armazenados, servidor/Bridge ou consulta direta à SEFAZ.
- Visual e cores mantidos; consulta individual e lote continuam no mesmo controller.

## Verificações e aceitação

A publicação exige CI GitHub aprovado para `web`, `extension` e `danfe-print`, mais as checagens do próprio workflow de release. O site é publicado separadamente pela integração existente com Cloudflare.

A aceitação física **não está aprovada** e deve ser executada em Chrome e Edge com o Portal real. Registro: `docs/testing/acceptance-results/v0.0.38.md`.
