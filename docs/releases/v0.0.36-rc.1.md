# NFe Agendamento 2.0 — v0.0.36-rc.1

Release candidate para validação física do hardening pós-auditoria, mantendo a extensão **0.2.12**.

## Objetivo

Disponibilizar um pacote instalável a partir da `main` para execução do gate físico em Windows, Chrome e Edge sem declarar aprovação antes do teste real.

## Hardening incluído

- CodeQL integrado ao mesmo CI usado pelo fluxo de release;
- releases estáveis continuam exigindo evidência física aprovada;
- release candidates `-rc.N` são publicadas como prerelease quando a aceitação ainda está pendente;
- testes comportamentais adicionais do background da extensão;
- pisos mínimos de cobertura para web e extensão;
- configuração Wrangler consolidada na raiz;
- documentação e rastreabilidade do gate físico.

## Escopo funcional

O código de produção da extensão permanece na versão **0.2.12**. Esta release candidate valida principalmente o pacote e o processo endurecido de entrega.

## Validação

O CI do commit da release candidate deve concluir com sucesso em `web`, `extension`, `danfe-print` e `codeql`.

A aceitação física permanece **PENDENTE** até execução real conforme `docs/testing/acceptance.md`.
