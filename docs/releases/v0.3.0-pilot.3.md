# NFe Agendamento v0.3.0 — PILOTO 3 (extensão MV3 independente)

**PRÉ-LANÇAMENTO EXPERIMENTAL, NÃO HOMOLOGADO PARA USO EMPRESARIAL.** Não substitui a release estável `v0.0.42`, não é implantação em produção e não altera a infraestrutura existente.

## Entregas acumuladas desde o piloto 2

- Interface completa incorporada à extensão para Chrome/Edge desktop, em janela popup própria; não precisa do site ou backend Cloudflare para executar.
- Workspace `apps/ui` consolidado, com transporte interno via `chrome.runtime`, validação de remetente e permissões limitadas ao Portal Nacional.
- Consulta unitária e em lote, validação do XML correspondente à chave, DANFE/impressão, recuperação por XML manual, downloads XML/CSV/ZIP e regras locais de fornecedores (comportamentos implementados; **uso fiscal real ainda não homologado**).
- Mini-IA local P0–P5 integrada ao piloto: classificação neural treinada em dados **sintéticos**, política de navegação somente em observação (`shadow mode`), diagnóstico local, análise de recorrências e revisão offline sem telemetria.
- Check obrigatório `web` do ruleset mantido com testes reais da UI local; gate de Mini-IA integrado ao CI e workflow de pré-lançamento.
- Smoke automatizado da extensão MV3 no Chromium e testes de consulta simulada, DANFE, lint, cobertura e auditoria de dependências antes da publicação deste pacote.

## Instalação de avaliação

1. Baixe o arquivo **NFeAgendamento-Extension-v0.3.0-pilot.3.zip** nos Assets desta release (não o Source code ZIP).
2. Extraia o ZIP inteiro em uma pasta. Use perfil de navegador separado do utilizado com a versão estável.
3. Em `chrome://extensions` ou `edge://extensions`, ative **Modo do desenvolvedor** e selecione **Carregar sem compactação** apontando para a pasta que contém `manifest.json`.
4. Clique no ícone do NFe Agendamento para abrir/focar o popup. Use dados sintéticos primeiro e não deixe duas versões competindo pela mesma operação fiscal.

## Limites obrigatórios

- **NÃO EXECUTADO:** aceite físico em Chrome e Edge Windows com Portal Nacional, hCaptcha manual, certificado quando exigido, XML de NF-e real autorizado, segunda consulta, lote, recuperação, PDF/DANFE e downloads. Os testes automáticos **não** substituem isso.
- A Mini-IA **não executa cliques neurais, não resolve hCaptcha e não treina com dados fiscais**. O fluxo fiscal permanece determinístico; o certificado fica com navegador/usuário.
- A `main`, release estável e Cloudflare permanecem inalteradas. Nenhum merge, deploy em produção ou desligamento de serviço foi realizado.
- Em caso de falha, remova a extensão piloto/perfil de testes; continue usando a edição oficial.
